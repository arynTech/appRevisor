# ModaSur app

App de nuestra tienda online de ropa (www.modasur.example).
La app carga la web directamente para no tener que mantener dos versiones.

- En la web el cliente puede crear su cuenta ("Mi cuenta"), ver pedidos y guardar direcciones.
- El pago de los pedidos se hace con tarjeta a través de Redsys en la web.
- Los pedidos se envían a domicilio en 48 h.
